# Démarrage rapide

Le projet utilise React/Vite pour l'interface et Flask pour l'API JSON. Suivez les étapes d'installation et de configuration MySQL du [README](README.md), puis lancez `./start.sh`.

- Interface : http://127.0.0.1:5173
- API : http://127.0.0.1:5000/health

Sans identifiants MySQL valides, l'interface reste consultable, mais l'inscription, la connexion et les opérations de compte ne peuvent pas enregistrer de données.
